# AI Platform Engineer Journey — Learning & Documentation Rules

## Target role
Senior AI Platform Engineer specializing in Python (primary), Golang (secondary), Java (third), distributed systems, Agentic AI, cloud infrastructure, Kubernetes, and production observability.

## Hard documentation rule
After each meaningful milestone:
- Capture concepts and mental models.
- Capture production rules and mistakes/debugging lessons.
- Capture interview takeaways.
- Keep a clear resume point.
- Produce/update Markdown suitable for committing to the repository.

## Learning style
2.5 hours/day. Learn the concept, implement it, test it, then explain why it exists. Avoid blind copy/paste.
