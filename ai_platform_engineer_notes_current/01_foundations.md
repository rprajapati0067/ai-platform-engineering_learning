# Foundations

## AI Platform
An AI Platform provides infrastructure and engineering capabilities to build, deploy, operate, secure, govern, and monitor AI/LLM applications.

An LLM alone does not provide enterprise private-data access, deterministic tools, orchestration, authentication/authorization, governance, observability, reliability, or scalable infrastructure.

## AI Platform Engineer vs ML Engineer
AI Platform Engineers build and operate the platform around models: APIs, orchestration, cloud/Kubernetes, observability, security, reliability, scaling, and provider integration.

ML Engineers primarily develop, train, evaluate, tune, and deploy ML models.

## Agent mental model
User → Goal → Plan → Use Tools → Observe Results → Reason Again → Complete Goal → Answer.

## Enterprise example
For data-lineage impact analysis, an agent can use lineage/search/database tools, reason over the results, and produce an impact analysis.
