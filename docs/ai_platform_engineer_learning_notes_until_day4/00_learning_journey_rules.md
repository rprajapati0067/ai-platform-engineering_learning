# AI Platform Engineer Journey — Documentation Rules

## Hard Rule
Maintain revision notes continuously throughout the AI Platform Engineer journey. After meaningful milestones, create/update downloadable Markdown notes suitable for committing to the repository.

## Learning Preferences
- Daily study time: ~2.5 hours
- Python: primary
- Golang: secondary
- Java: third
- Understand the concept first, then implement, test, and explain the architecture.
- Prefer production-oriented reasoning over syntax memorization.
- Build one evolving Enterprise AI Platform project alongside the learning.

## Note Structure
Each meaningful milestone should capture:
1. Concept
2. Why it matters
3. Architecture / flow
4. Implementation lessons
5. Important rules
6. Common mistakes
7. Interview takeaways
8. Practical patterns where useful
9. What was implemented
10. Revision questions
